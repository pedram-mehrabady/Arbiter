# Lessons learned

The factory's memory of past problems, so none repeats. Owned by the **lessons loop**
(engine/MASTER-DIRECTIVES.md §8): the conductor captures failures to `.arbiter/error-logs/<task>/`,
the `debugger` writes `debug-notes.md`, and the **`tech-writer`** distills each into a lesson
here **and** proposes a one-line addition to the relevant agent's rule book (human confirms;
auto for the safe class). Agents read the lessons that apply to them via their context manifest.

Format:
```
## L-NNN — YYYY-MM-DD [agent]
**Mistake:** what went wrong (root cause, not just the symptom)
**Rule:** the rule that prevents it
**Applies to:** scope
```
